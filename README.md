# UnderTell-2
UnderTell 2 is a Java console RPG in which players explore rooms, encounter enemies, manage a party, and use attacks, defensive actions, skills, and consumable items to survive. The project includes specialized character and enemy classes, randomized encounters and item drops, experience-based progression inventory management, and turn-based combat


# How To Run

To play the game, make sure Java is installed. Open the folder containing UnderTell2.jar, type cmd in the address bar, and press Enter. Then enter:

"java -jar UnderTell2.jar"
